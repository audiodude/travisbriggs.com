Many have theorized that the coding **harness** matters more than the backend model when doing AI assisted or "vibe" coding. The harness is the set of system prompts, instructions for tool use, ways of loading skills/MCP and utilizing them, patterns for filesystem access, permissions models, etc, that actually makes Claude _Code_ different than vanilla Claude (which can also write code on its own).

I largely agree with this position, based on my general mistrust of [[ai-coding-benchmarks| AI coding benchmarks]].
